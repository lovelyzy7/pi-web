# Catppuccin 文件图标

本目录包含 [Catppuccin Icons for VSCode](https://github.com/catppuccin/vscode-icons) 的一个精选子集，版本 `v1.26.0`（`b6915da9f6889b683a110aa747de96c2820a537d`）。

- `latte/` 用于 Pi Web 的浅色主题。
- `mocha/` 用于 Pi Web 的深色主题。
- Pi Web 使用 SVG 的 alpha 通道作为遮罩并应用 `var(--text-dim)`，
  因此渲染出的图标在两套主题下都保持单色。
